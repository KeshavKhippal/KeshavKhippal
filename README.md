## 🚩 Flagship Project

### MedAuth Sentinel — Autonomous Prior-Authorization & Appeals Agent
**Veersa Hackathon 2026** · [🔗 View repository](https://github.com/KeshavKhippal/Veersa-Victors)

A 3-agent LLM system (Intake → Decision → **Critic**) that processes healthcare prior-authorization requests in seconds with full reasoning transparency. The CriticAgent adversarially reviews every decision and forces a revision when it finds a missed policy exception — a self-correcting loop that's genuinely agentic. Ships with a React UI, editable live prompts (Prompt Studio), pytest suites, and Docker/Render/Vercel deploy configs.
`Python · FastAPI · Groq (llama-3.3-70b) · React · Docker · pytest`
